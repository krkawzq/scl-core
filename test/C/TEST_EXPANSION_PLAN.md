# SCL 测试用例扩展计划

## 目标

**当前**：~240个测试用例  
**目标**：~480个测试用例  
**策略**：系统性覆盖，无重复

## 新增测试场景分类

### 1. 边界条件扩展 (50个新用例)

#### 维度边界
- 1×1, 1×n, n×1 矩阵（最小非平凡）
- 极大维度（10000×10000）
- 极端长宽比（1×10000, 10000×1）
- 维度为2的幂次（64, 128, 256, 512, 1024）

#### NNZ边界
- nnz=1（最小）
- nnz=rows*cols（完全密集）
- nnz接近上界（rows*cols - 1）
- 各种密度（0.001, 0.01, 0.1, 0.5, 0.9）

#### 值边界
- 零值（0.0, 0, 0u）
- 最小正值（epsilon）
- 最大值（Int8:127, Uint8:255, etc.）
- 最小负值（Int8:-128, Int16:-32768）
- NaN, Inf（仅浮点）

### 2. 错误情况扩展 (40个新用例)

#### 参数组合错误
- 所有参数NULL的组合
- 维度不一致
- nnz与数组长度不匹配
- 类型枚举边界值（-1, 255, INT_MAX）

#### 索引越界场景
- row=-1, row=INT64_MAX
- col=-1, col=INT64_MAX
- at/get/exists 各种越界组合

#### 类型错误
- 混用类型（int32数组传给uint32）
- 索引类型不匹配
- 布局类型错误

### 3. 数据分布测试 (40个新用例)

#### 稀疏模式
- 对角矩阵（主对角线）
- 上/下三角矩阵
- 带状矩阵（bandwidth=1,2,3,5）
- 块对角矩阵
- 随机稀疏（各种密度）

#### 特殊值分布
- 全1矩阵
- 全-1矩阵
- 交替符号（+1,-1,+1,-1）
- 递增序列（1,2,3,4,...）
- 幂次序列（1,2,4,8,16,...）

#### 排序状态
- 完全排序
- 完全逆序
- 部分排序
- 随机顺序

### 4. 整数类型专项测试 (50个新用例)

#### Int8/Int16/Int32/Int64 各10个
- 正值范围测试
- 负值范围测试
- 边界值测试
- 溢出检测
- 缩放截断测试
- 类型转换测试

#### Uint8/Uint16/Uint32/Uint64 各10个
- 小值范围（0-10）
- 大值范围（接近max）
- 边界值（0, max）
- 缩放行为
- 二进制操作

### 5. 操作函数扩展 (40个新用例)

#### transpose详细测试
- 各种矩阵大小
- CSR↔CSC往返
- 连续转置（A^T^T^T...）
- 不同密度

#### scale详细测试
- 各种标量值（-100到100）
- 特殊值（NaN, Inf, epsilon）
- 整数截断行为
- 溢出检测

#### clone详细测试
- 修改原矩阵不影响克隆
- 克隆后独立操作
- 内存独立性验证
- 各种缓冲策略

### 6. 数值正确性测试 (30个新用例)

#### 与手工计算对比
- 已知小矩阵的精确值
- 逐元素验证
- 稀疏模式验证

#### 数学性质验证
- (A^T)^T = A
- scale(A, 0) 后所有非零值为0
- clone(A) 与 A 数值相等
- 对称矩阵转置不变

### 7. 性能测试扩展 (30个新用例)

#### 不同大小性能
- 10×10 到 10000×10000
- 各种密度
- 各种类型

#### 操作性能
- 批量创建
- 批量操作
- 内存分配模式

### 8. 组合测试 (40个新用例)

#### 操作链
- create → transpose → scale → clone
- create → clone → scale → transpose
- 复杂操作序列

#### 混合类型场景
- Real64 identity → scale
- Int32 zeros → from_coo填充
- Uint8 小矩阵操作链

### 9. 并发/多线程测试 (20个新用例)

#### 线程安全
- 多线程同时创建
- 多线程同时查询
- 错误状态隔离

### 10. 内存测试 (20个新用例)

#### 生命周期
- 创建-销毁循环
- 内存泄漏检测
- 大量小矩阵
- 少量大矩阵
